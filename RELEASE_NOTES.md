# FPV GCS 0.1.10

Керування реальними USB-відеозахватами Raspberry Pi з Windows FPV GCS.

## Встановлення Raspberry Pi з нуля

**[Відкрити покрокову інструкцію для Raspberry Pi 3 Model B](https://github.com/Sokolovskiy/FPV_GCS/blob/main/docs/pi-setup.md).**
Її також можна завантажити з Assets цього релізу як `FPV-GCS-Pi-Install-UK.md`.

Інструкція веде від порожньої microSD до перевірки готового ретранслятора:
запис Raspberry Pi OS Lite (64-bit), вхід із Windows, установлення залежностей,
завантаження й перевірка Pi-пакета, Ethernet, UART PL011 на Pi 3,
відео, RC спочатку без UART, фізичний CRSF, автозапуск і підключення Herelink.
Для кожного етапу наведено команди та очікуваний результат, наприкінці —
таблицю поширених помилок.

Чиста установка й продуктивність поточного програмного H.264-кодування
на Pi 3 Model B ще потребують перевірки на самій платі. Інструкція включає
перевірку навантаження; гарантовані FPS/затримку для Pi 3 не заявлено.

## Пакети

- `FPV-GCS-Setup-0.1.10-win64.exe` — інсталятор Windows 10/11 x64.
- `FPV-GCS-Portable-0.1.10-win64.zip` — розпакуйте всю папку та запустіть `FPV GCS.exe`.
- `FPV-GCS-Pi-0.1.10.zip` — Python-скрипти та systemd-файли Pi, інструкція в `pi/systemd/README.md`.
- `SHA256SUMS-0.1.10.txt` — контрольні суми всіх трьох пакетів.
- `TORO.HERELINK.yml` — темплейт пульта EdgeTX; інструкція встановлення нижче.
- `FPV-GCS-Pi-Install-UK.md` — українська інструкція встановлення на чисту Pi.

Qt, SDL та GStreamer включено до Windows-пакетів. Для нових налаштувань
камер потрібне оновлення Pi; Windows-інсталятор сам Pi не змінює.

## Зміни

- Селектор USB-камери й кнопка Settings над таблицею RC-каналів; список відкривається вниз.
- Спільний стан активної камери в головному вікні та Video Capture Settings.
- Автовибір камери на Pi, відновлення preferred device та окрема конфігурація кожного захвату.
- Стабільні USB ID, оновлення списку при підключенні/відключенні, очікування без камер.
- Фізичне відключення USB обробляється окремо від відсутності CVBS-сигналу.
- Реальні V4L2 формати, FPS, inputs, standards та image controls із driver min/max/step/default.
- Застосування формату кнопкою в Capture Format і контрольований restart лише відеоконвеєра.
- Image controls оновлюються без стрибків прокрутки та втрати чернетки формату; однакові числові поля зі стрілками.
- У Stream Status показано negotiated caps, bitrate та доступні лічильники; H.264 Encoding із форми прибрано.
- Один вихідний потік H.264/RTP/UDP на `192.168.144.3:5602`; RC/CRSF, watchdog, UART та telemetry не змінені.

## Темплейт пульта TORO HERELINK

[Завантажити TORO HERELINK.yml](https://github.com/Sokolovskiy/FPV_GCS/releases/download/v0.1.10/TORO.HERELINK.yml).

Темплейт містить мікси та налаштування USB Joystick для 16 каналів FPV GCS.
У файлі вказано EdgeTX 2.10.6. Інструкція орієнтована на TX16S із кольоровим
екраном; сумісність цього файлу з іншими пультами та версіями потребує перевірки.

### 1. Встановлення темплейта

Збережіть завантажений файл під назвою `TORO HERELINK.yml`
(GitHub замінює пробіл у назві вкладення на крапку).

1. Збережіть резервну копію SD-карти та налаштувань пульта.
2. Відкрийте SD-карту через кардридер або режим USB Storage пульта.
3. Скопіюйте `TORO HERELINK.yml` у `/TEMPLATES/2.Personal/` на SD-карті.
   Якщо папки немає, створіть її. Збережіть розширення `.yml`.
4. Безпечно від'єднайте накопичувач. На пульті відкрийте **Manage Models →
   New Model → 2.Personal → TORO HERELINK**.
5. Виберіть створену конфігурацію як активну; за потреби перейменуйте її.
   EdgeTX створює нову конфігурацію з темплейта, тому чинні конфігурації
   не потрібно замінювати вручну.

Порядок створення з темплейта описано в
[інструкції EdgeTX 2.10](https://manual.edgetx.org/v2.10/color-radios/select-model).

### 2. Підключення через USB

1. У створеній конфігурації відкрийте **Model Setup** і встановіть
   **Internal RF = OFF**, **External RF = OFF**. У вихідному темплейті зовнішній
   модуль налаштовано на CRSF; для схеми USB → FPV GCS радіомодулі пульта
   слід вимкнути. CRSF до ES900TX у цій схемі передає Raspberry Pi.
2. Перевірте **USB Joystick**:
   - режим **Advanced**;
   - **Interface = Joystick**, **Circular cutout = None**;
   - CH1–CH6: **Axis X, Y, Z, rotX, rotY, rotZ** відповідно;
   - CH7–CH16: **Axis Slider** для кожного каналу.
3. Під'єднайте пульт до ПК кабелем USB з передаванням даних і виберіть
   **USB Joystick**, якщо пульт пропонує вибір режиму.
   Після зміни USB-налаштувань від'єднайте та знову під'єднайте кабель.
4. Відкрийте FPV GCS і виберіть пульт. Для розпізнаного 16-канального
   USB-формату новий профіль автоматично зіставляє CH1–CH16.
   Збережені призначення попереднього профілю залишаються чинними — перевірте їх.

Параметри USB та вимкнення RF описано в
[USB Joystick — EdgeTX 2.10](https://manual.edgetx.org/v2.10/color-radios/model-settings/model-setup/usb-joystick).

### 3. Канали темплейта

| Канал | Джерело | Назва або призначення у файлі |
| --- | --- | --- |
| CH1 | Ail через I0 | AilR / Roll |
| CH2 | Ele через I1 | Elev / Pitch |
| CH3 | Thr через I2 | Motor / Throttle |
| CH4 | Rud через I3 | Rudder / Yaw |
| CH5 | SF | ARM |
| CH6 | SB | BEEPER |
| CH7 | SC | MODE |
| CH8 | SG | Без назви |
| CH9 | NONE | VTX CH; орган керування не призначений |
| CH10 | SA | VTX PO |
| CH11 | SD | VTX PO |
| CH12 | SH | SERVA |
| CH13 | P1 | Без назви |
| CH14 | P2 | Без назви |
| CH15 | SL1 | RX PO |
| CH16 | SL2 | TX PO |

Назви взято з темплейта. Вони не налаштовують функції польотного контролера,
VTX або приймача: відповідність AUX-каналів потрібно налаштувати окремо.
CH9 передається серед USB-каналів, але не має призначеного органа керування.

### 4. Перевірка перед використанням

Перевіряйте на стенді зі знятими пропелерами.

1. У моніторі каналів пульта перевірте стіки, перемикачі, ручки та слайдери
   за таблицею. Для CH9 зміна від органів керування не очікується.
2. У FPV GCS перевірте ті самі канали, напрямки, крайні значення та всі
   положення перемикачів. Очікуваний діапазон RC — 1000–2000,
   нейтраль центрованих каналів — близько 1500.
3. Окремо перевірте CH3 (газ) та CH5 (ARM): мінімальний газ і положення
   disarm мають відповідати налаштуванням вашого польотного контролера.
4. Перевірте проходження каналів до приймача/FC та failsafe при від'єднанні USB
   і втраті зв'язку ПК–Pi. Це апаратна перевірка вашої конфігурації;
   наявність темплейта її не замінює.

Файл також посилається на зображення `Cva142HD.png` та віджети оформлення.
Вони не входять до цього темплейта; відсутнє оформлення можна замінити
в налаштуваннях пульта.

## Оновлення Pi

Збережіть наявні файли перед заміною. У користувацькому каталозі
`~/fpv-gcs-udp/` оновіть `video_capture.py` та `systemd/launch.py` з Pi-пакета.
Встановіть залежності й перезапустіть лише відеосервіс:

```sh
sudo apt-get install python3-gi gir1.2-gstreamer-1.0 v4l-utils psmisc
systemctl --user restart fpv-video.service
```

API: `192.168.144.20:5603`, Windows peer: `192.168.144.3`.
Конфігурація: `~/.config/fpv-gcs/video-capture.json`. Для захватів без
серійного номера стабільна ідентифікація прив'язана до USB-порту.

## Перевірки та межі

Windows build та 30 QtTest перевірок пройдено. Python-набір: 64 успішні,
одна Linux-only перевірка пропущена на Windows; 17 video tests також
виконано на Pi. На реальних MACROSILICON/ARKMICRO перевірено перемикання
джерел, декодування H.264, controls, capture format та service restart.
Фізичне USB unplug/replug і повний reboot Pi не виконувалися. Інсталятор
не має цифрового підпису видавця.

# FPV GCS 0.1.9

Перша опублікована Windows-збірка: відео H.264, USB-пульт і 16 RC-каналів в одному вікні.

## Завантаження

| Файл | Для чого |
| --- | --- |
| **FPV-GCS-Setup-0.1.9-win64.exe** | Інсталятор українською та англійською. Встановлення для поточного користувача без прав адміністратора; ярлик у меню «Пуск», опційно на робочому столі. |
| **FPV-GCS-Portable-0.1.9-win64.zip** | Без встановлення: розпакуйте всю папку й запустіть `FPV GCS.exe`. |
| **SHA256SUMS.txt** | Контрольні суми обох пакетів. |

Windows 10/11 x64. Qt, SDL і GStreamer уже включено. Python для Windows-додатка не потрібен.

## Можливості

- Приймання RTP/H.264 з відображенням через Direct3D11 та автоматичним відновленням відеоприймача.
- 16 незалежних RC-каналів, призначення органів пульта рухом і збереження профілів.
- Передавання RC через UDP з цільовою частотою 100 Гц та автоматичне відновлення відомого USB-пульта.
- Налаштування ширини колонок, поділ відео/RC і повноекранний режим **F11**.

## Перший запуск

1. Встановіть додаток або розпакуйте portable-архів.
2. Налаштуйте Ethernet ПК: `192.168.144.3`. RC-приймач Pi: `192.168.144.20:14600`; RTP/H.264 надходить на ПК на порт `5602`.
3. Підключіть USB-пульт, виберіть його та перевірте призначення каналів. Профілі зберігаються локально, до пакета не включено профілі розробника.

## Перевірки та межі

26 автоматичних перевірок QtTest пройдено. Перед використанням перевірте канали й failsafe на стенді зі знятими пропелерами. Частота 100 Гц є цільовою, а не гарантією Windows реального часу. Інсталятор не має цифрового підпису видавця; Windows може показати попередження про невідомого видавця. Апаратні перевірки на іншому ПК цим релізом не засвідчуються.
