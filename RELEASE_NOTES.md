# FPV GCS 0.1.9

Перша опублікована Windows-збірка: відео H.264, USB-пульт і 16 RC-каналів в одному вікні.

## Завантаження

| Файл | Для чого |
| --- | --- |
| **FPV-GCS-Setup-0.1.9-win64.exe** | Інсталятор українською та англійською. Встановлення для поточного користувача без прав адміністратора; ярлик у меню «Пуск», опційно на робочому столі. |
| **FPV-GCS-Portable-0.1.9-win64.zip** | Без встановлення: розпакуйте всю папку й запустіть `FPV GCS.exe`. |
| **SHA256SUMS.txt** | Контрольні суми обох пакетів. |

Windows 10/11 x64. Qt, SDL і GStreamer уже включено. Python для Windows-додатка не потрібен.

## Можливості

- Приймання RTP/H.264 з відображенням через Direct3D11 та автоматичним відновленням відеоприймача.
- 16 незалежних RC-каналів, призначення органів пульта рухом і збереження профілів.
- Передавання RC через UDP з цільовою частотою 100 Гц та автоматичне відновлення відомого USB-пульта.
- Налаштування ширини колонок, поділ відео/RC і повноекранний режим **F11**.

## Перший запуск

1. Встановіть додаток або розпакуйте portable-архів.
2. Налаштуйте Ethernet ПК: `192.168.144.3`. RC-приймач Pi: `192.168.144.20:14600`; RTP/H.264 надходить на ПК на порт `5602`.
3. Підключіть USB-пульт, виберіть його та перевірте призначення каналів. Профілі зберігаються локально, до пакета не включено профілі розробника.

## Перевірки та межі

26 автоматичних перевірок QtTest пройдено. Перед використанням перевірте канали й failsafe на стенді зі знятими пропелерами. Частота 100 Гц є цільовою, а не гарантією Windows реального часу. Інсталятор не має цифрового підпису видавця; Windows може показати попередження про невідомого видавця. Апаратні перевірки на іншому ПК цим релізом не засвідчуються.
