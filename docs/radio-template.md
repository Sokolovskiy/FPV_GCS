# Темплейт пульта TORO HERELINK

[Завантажити TORO HERELINK.yml](templates/TORO%20HERELINK.yml).

Темплейт містить мікси та налаштування USB Joystick для 16 каналів FPV GCS.
У файлі вказано EdgeTX 2.10.6. Інструкція орієнтована на TX16S із кольоровим
екраном; сумісність цього файлу з іншими пультами та версіями потребує перевірки.

## 1. Встановлення темплейта

1. Збережіть резервну копію SD-карти та налаштувань пульта.
2. Відкрийте SD-карту через кардридер або режим USB Storage пульта.
3. Скопіюйте `TORO HERELINK.yml` у `/TEMPLATES/2.Personal/` на SD-карті.
   Якщо папки немає, створіть її. Збережіть розширення `.yml`.
4. Безпечно від'єднайте накопичувач. На пульті відкрийте **Manage Models →
   New Model → 2.Personal → TORO HERELINK**.
5. Виберіть створену конфігурацію як активну; за потреби перейменуйте її.
   EdgeTX створює нову конфігурацію з темплейта, тому чинні конфігурації
   не потрібно замінювати вручну.

Порядок створення з темплейта описано в
[інструкції EdgeTX 2.10](https://manual.edgetx.org/v2.10/color-radios/select-model).

## 2. Підключення через USB

1. У створеній конфігурації відкрийте **Model Setup** і встановіть
   **Internal RF = OFF**, **External RF = OFF**. У вихідному темплейті зовнішній
   модуль налаштовано на CRSF; для схеми USB → FPV GCS радіомодулі пульта
   слід вимкнути. CRSF до ES900TX у цій схемі передає Raspberry Pi.
2. Перевірте **USB Joystick**:
   - режим **Advanced**;
   - **Interface = Joystick**, **Circular cutout = None**;
   - CH1–CH6: **Axis X, Y, Z, rotX, rotY, rotZ** відповідно;
   - CH7–CH16: **Axis Slider** для кожного каналу.
3. Під'єднайте пульт до ПК кабелем USB з передаванням даних і виберіть
   **USB Joystick**, якщо пульт пропонує вибір режиму.
   Після зміни USB-налаштувань від'єднайте та знову під'єднайте кабель.
4. Відкрийте FPV GCS і виберіть пульт. Для розпізнаного 16-канального
   USB-формату новий профіль автоматично зіставляє CH1–CH16.
   Збережені призначення попереднього профілю залишаються чинними — перевірте їх.

Параметри USB та вимкнення RF описано в
[USB Joystick — EdgeTX 2.10](https://manual.edgetx.org/v2.10/color-radios/model-settings/model-setup/usb-joystick).

## 3. Канали темплейта

| Канал | Джерело | Назва або призначення у файлі |
| --- | --- | --- |
| CH1 | Ail через I0 | AilR / Roll |
| CH2 | Ele через I1 | Elev / Pitch |
| CH3 | Thr через I2 | Motor / Throttle |
| CH4 | Rud через I3 | Rudder / Yaw |
| CH5 | SF | ARM |
| CH6 | SB | BEEPER |
| CH7 | SC | MODE |
| CH8 | SG | Без назви |
| CH9 | NONE | VTX CH; орган керування не призначений |
| CH10 | SA | VTX PO |
| CH11 | SD | VTX PO |
| CH12 | SH | SERVA |
| CH13 | P1 | Без назви |
| CH14 | P2 | Без назви |
| CH15 | SL1 | RX PO |
| CH16 | SL2 | TX PO |

Назви взято з темплейта. Вони не налаштовують функції польотного контролера,
VTX або приймача: відповідність AUX-каналів потрібно налаштувати окремо.
CH9 передається серед USB-каналів, але не має призначеного органа керування.

## 4. Перевірка перед використанням

Перевіряйте на стенді зі знятими пропелерами.

1. У моніторі каналів пульта перевірте стіки, перемикачі, ручки та слайдери
   за таблицею. Для CH9 зміна від органів керування не очікується.
2. У FPV GCS перевірте ті самі канали, напрямки, крайні значення та всі
   положення перемикачів. Очікуваний діапазон RC — 1000–2000,
   нейтраль центрованих каналів — близько 1500.
3. Окремо перевірте CH3 (газ) та CH5 (ARM): мінімальний газ і положення
   disarm мають відповідати налаштуванням вашого польотного контролера.
4. Перевірте проходження каналів до приймача/FC та failsafe при від'єднанні USB
   і втраті зв'язку ПК–Pi. Це апаратна перевірка вашої конфігурації;
   наявність темплейта її не замінює.

Файл також посилається на зображення `Cva142HD.png` та віджети оформлення.
Вони не входять до цього темплейта; відсутнє оформлення можна замінити
в налаштуваннях пульта.
